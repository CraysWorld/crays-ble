# CRAYS BLE source

**Current operating environment — 24 November 2026:** CRAYS development, builds, testing, previews and server operation use AWS. Vercel, Neon and XXL references in older captures describe historical environments. This hosting status does not claim completion of every product flow. [Current AWS and source guidance](https://github.com/CraysWorld/.github/blob/main/docs/aws-operating-status.md).

`crayschat-android/` and `crayscircle-ios/` contain the separate original platform projects. This repository is device-side source, not an AWS server deployment; retain each component’s original notices and native build requirements.

Use the existing AWS development and release process. Keep private configuration, customer data and runtime bindings outside Git. Source publication does not start or certify a deployment.
